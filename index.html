Дарс: «Намудҳо ва таркиби таъминоти барномавӣ»

① Таъминот чист? ② Намудҳо ③ Системавӣ ④ Амалӣ ⑤ Утилитаҳо ⑥ Таркиб ⑦ Мисолҳо ⑧ Хулоса 📝 Тест
1 Таъминоти барномавӣ чист?

Таъминоти барномавӣ (англ. software — «нармӣ») — ин маҷмӯи барномаҳо, дастурҳо ва маълумотест, ки ба компютер мефаҳмонанд, ки чӣ кор кунад ва чӣ тавр кор кунад.

Компютер аз ду қисми асосӣ иборат аст:

🔩

Таъминоти техникӣ (hardware)

Қисмҳои физикии компютер: монитор, клавиатура, муш, протсессор, хотира, диск.

🧠

Таъминоти барномавӣ (software)

Барномаҳое, ки компютерро идора мекунанд: системаи амалиётӣ, барномаҳои корбар, утилитаҳо.

Мисоли осон: Компютер ба бадани одам монанд аст — hardware «дасту пой» ва «майна»-и ӯст, ал software «дониш ва фикр»-и ӯст. Бе барнома компютер танҳо як қуттии оҳанӣ мебошад! 🧰
2 Намудҳои таъминоти барномавӣ

Ҳамаи барномаҳо ба се гурӯҳи асосӣ ҷудо мешаванд. Ҳар гурӯҳ вазифаи худро дорад:

⚙️

1. Таъминоти системавӣ

Компютерро идора мекунад ва ба дигар барномаҳо имкон медиҳад, ки кор кунанд.

📊

2. Таъминоти амалӣ

Барои иҷрои вазифаҳои мушаххаси корбар: навиштан, ҳисоб, тасвир, филм, интернет.

🧰

3. Барномаҳои хизматрасон

Утилитаҳо — нигоҳдорӣ, тозакунӣ, ҳифз ва беҳтар кардани кори компютер.

👨‍💻

4. Воситаҳои барномасозӣ

Барномаҳо барои сохтани барномаҳои нав: Python, Pascal, Scratch.

Дар хотир нигоҳ дор! Дар китобҳои гуногун ин гурӯҳҳоро ба таври гуногун ҷудо мекунанд. Дар синфи 7 мо асосан се намуди асосиро меомӯзем: системавӣ, амалӣ ва хизматрасон.
3 Таъминоти системавӣ

Таъминоти системавӣ — ин маҷмӯи барномаҳоест, ки кори тамоми компютерро идора мекунанд. Онҳо «сардори» тамоми барномаҳо мебошанд.

🪟

Системаи амалиётӣ

Барномаи асосии компютер. Мисол: Windows, Linux, macOS, Android, iOS.

🔌

Драйверҳо

Барномаҳои махсус барои идоракунии дастгоҳҳо: принтер, муш, садо, видеокорт.

🛠️

Барномаҳои хизматрасон

Утилитаҳо — барои нигоҳдорӣ ва танзими компютер.

Вазифаҳои системаи амалиётӣ:
  • Идоракунии дастгоҳҳои компютер
  • Иҷрои барномаҳои корбар
  • Нигоҳдории файлу ҳуҷҷатҳо
  • Муҳофизати маълумот ва тақсими хотира

Мисол: Вақте ки шумо компютерро дармегиред, аввал Windows ё Linux бор мешавад — ин системаи амалиётӣ аст. Баъд шумо метавонед дигар барномаҳоро кушоед.

4 Таъминоти амалии барномавӣ

Таъминоти амалӣ (прикладной) — ин барномаҳое мебошанд, ки корбар барои иҷрои кори мушаххаси худ истифода мебарад. Инҳо он барномаҳое ҳастанд, ки мо ҳар рӯз мебинем.

📝

Барномаҳои матнӣ

Барои навиштан ва таҳрири ҳуҷҷатҳо: Microsoft Word, Google Docs, Notepad.

📈

Барномаҳои ҷадвалӣ

Барои ҳисобҳо ва диаграммаҳо: Microsoft Excel, Google Sheets.

🎨

Барномаҳои графикӣ

Барои расм ва сурат: Paint, Photoshop, GIMP, CorelDRAW.

🌐

Браузерҳо

Барои дидани сайтҳо: Google Chrome, Firefox, Opera, Edge.

🎬

Барномаҳои мультимедиа

Барои филм, мусиқӣ ва видео: VLC, Windows Media Player, CapCut.

🎮

Барномаҳои бозӣ

Барои фароғат: Minecraft, Roblox, FIFA, Chess.

Қоидаи оддӣ: Агар барнома ба шумо барои кори мушаххас кӯмак кунад — ин таъминоти амалӣ аст. 🎯
5 Барномаҳои хизматрасон (утилитаҳо)

Утилитаҳо — ин барномаҳои хурд, вале хеле муҳиме мебошанд, ки барои нигоҳдорӣ, ҳифз ва беҳтар кардани кори компютер хизмат мекунанд.

🛡️

Антивирусҳо

Компютерро аз вирусҳо ҳифз мекунанд: Kaspersky, Avast, Windows Defender.

🗜️

Архиваторҳо

Файлҳоро ҷамъ ва фишурда мекунанд: WinRAR, 7-Zip, WinZip.

🧹

Тозакунандаҳо

Файлҳои нолозимро нест мекунанд: CCleaner, Disk Cleanup.

💾

Нусхабардорӣ

Маълумотро нусхабардорӣ мекунанд: Acronis, Windows Backup.

📀

Дефрагментаторҳо

Дискро танзим мекунанд, то компютер тезтар кор кунад.

🔥

Фаерволҳо

Аз ҳамлаҳои интернетӣ ҳифз мекунанд.

Мисоли воқеӣ: Вақте ки компютери шумо «суст» мешавад, шумо CCleaner-ро истифода мебаред — ин утилита аст. Вақте ки файли калонро ба дӯстатон мефиристед, онро бо WinRAR фишурда мефиристед — ин ҳам утилита аст. 📦

7 Мисолҳои воқеӣ

Биёед бубинем, ки як рӯзи оддии корбар чӣ гуна барномаҳоро истифода мебарад:

🌅 7:00 — Компютерро дармекунам
Аввал Windows 11 (таъминоти системавӣ) бор мешавад.
☕ 7:05 — Почтаро мебинам
Браузери Google Chrome (таъминоти амалӣ)-ро мекушоям.
📝 8:00 — Вазифаи хонагӣ
Дар Microsoft Word (таъминоти амалӣ) реферат менависам.
📊 9:30 — Ҳисобҳо
Дар Microsoft Excel (таъминоти амалӣ) ҷадвал месозам.
🛡️ 10:00 — Сканкунӣ
Бо антивирус (утилита) компютерро месанҷам.
📦 10:30 — Фиристодани файл
Бо WinRAR (утилита) файлҳоро фишурда мефиристам.
🎮 16:00 — Фароғат
Дар Minecraft (таъминоти амалӣ) бозӣ мекунам.
🌙 22:00 — Хомӯш кардан
Компютерро хомӯш мекунам — системаи амалиётӣ ҳамаи барномаҳоро мебандад.
8 Хулоса

Дар ин дарс мо омӯхтем, ки:

  • Таъминоти барномавӣ — маҷмӯи барномаҳоест, ки компютерро идора мекунад.
  • Он ба се гурӯҳи асосӣ ҷудо мешавад: системавӣ, амалӣ ва хизматрасон.
  • Таъминоти системавӣ — асоси компютер: системаи амалиётӣ, драйверҳо.
  • Таъминоти амалӣ — барномаҳо барои корбар: Word, Excel, Paint, Chrome.
  • Утилитаҳо — барои нигоҳдорӣ ва ҳифзи компютер: антивирус, архиватор.
  • Ҳамаи ин қисмҳо якҷоя таркиби таъминоти барномавӣ-ро ташкил медиҳанд.
  • Бе таъминоти барномавӣ компютер кор карда наметавонад!
🎓 Ба ёд гиред: Hardware — бадан, Software — рӯҳ. Ҳар ду якҷоя компютерро зинда мекунанд!
